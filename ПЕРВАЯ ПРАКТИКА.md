# Первая практика ADO.NET

**Цель:** запустить готовую программу, понять четыре основных действия и изменить один запрос.
Начните с одного файла `practice/Program.cs`. Настройки подключения уже подготовлены.

## Шаг 1 Запустите программу

В терминале Codespaces из корня репозитория выполните:

```bash
dotnet run --project practice
```

На новой учебной базе вы увидите:

```text
Анна Иванова — ИСП-21
Борис Петров — ИСП-21
Вера Соколова — ИСП-22
```

Это данные из таблицы `Students` в SQL Server. Программа получает их при каждом запуске.
Если преподаватель или вы уже изменяли базу, результат может отличаться.

## Шаг 2 Найдите четыре действия

Откройте `practice/Program.cs`. Полная программа выглядит так:

```csharp
using Microsoft.Data.SqlClient;

// 1. Подключаемся к готовой учебной базе.
using var connection = new SqlConnection(LabDb.ConnectionString);
connection.Open();

// 2. Готовим запрос: получить имя и группу каждого студента.
string sql = "SELECT FullName, GroupName FROM dbo.Students ORDER BY StudentId;";
using var command = new SqlCommand(sql, connection);

// 3. Выполняем запрос.
using var reader = command.ExecuteReader();

// 4. Читаем строки результата по одной.
while (reader.Read())
{
    string name = reader.GetString(0);
    string group = reader.GetString(1);

    Console.WriteLine(name + " — " + group);
}
```

Не нужно переписывать программу по памяти. Сначала запустите её, затем меняйте по одной строке.

## Шаг 3 Разберите подключение

```csharp
using var connection = new SqlConnection(LabDb.ConnectionString);
connection.Open();
```

`connection` — объект подключения к базе. `Open()` открывает подключение.
В `LabDb.ConnectionString` уже находятся адрес сервера, имя базы и данные входа.
Файл `LabDb.cs` менять сейчас не требуется.

`using var` означает, что ресурс будет освобождён после выполнения программы.
Пока запоминайте это как правило: подключение, команду и reader объявляем с `using var`.

Первая строка `using Microsoft.Data.SqlClient;` имеет другое назначение:
она позволяет использовать короткие имена классов провайдера, например `SqlConnection`.

## Шаг 4 Разберите запрос

```csharp
string sql = "SELECT FullName, GroupName FROM dbo.Students ORDER BY StudentId;";
```

Это переменная со строкой SQL:

- `SELECT FullName, GroupName` — получить имя и группу.
- `FROM dbo.Students` — из таблицы студентов.
- `ORDER BY StudentId` — вывести записи в порядке идентификаторов.

```csharp
using var command = new SqlCommand(sql, connection);
```

Создаём команду: указываем, какой запрос выполнить и через какое подключение.

## Шаг 5 Разберите чтение результата

```csharp
using var reader = command.ExecuteReader();
```

`ExecuteReader()` выполняет запрос и возвращает объект для чтения строк.

```csharp
while (reader.Read())
```

`Read()` переходит к очередной строке. Пока строка есть, выполняется тело цикла.

```csharp
string name = reader.GetString(0);
string group = reader.GetString(1);
```

Читаем текст из двух столбцов. Их номера начинаются с нуля и следуют порядку в запросе:

| Номер | Столбец | Пример |
| --- | --- | --- |
| `0` | `FullName` | Анна Иванова |
| `1` | `GroupName` | ИСП-21 |

`Console.WriteLine` выводит имя и группу на экран. Весь путь:

```text
Подключиться → подготовить запрос → выполнить → прочитать и вывести строки
```

## Задание 1 Измените оформление

Замените только строку вывода:

```csharp
Console.WriteLine("Студент: " + name + ", группа: " + group);
```

Сохраните файл и снова выполните `dotnet run --project practice`.
Ожидается тот же список, но в виде `Студент: Анна Иванова, группа: ИСП-21`.

## Задание 2 Покажите одну группу

В исходной программе замените только значение `sql`:

```csharp
string sql = "SELECT FullName, GroupName FROM dbo.Students WHERE GroupName = N'ИСП-21' ORDER BY StudentId;";
```

Должны остаться Анна и Борис. Затем замените ИСП-21 на ИСП-22: должна остаться Вера.
Условие `WHERE` отбирает строки.

Здесь название группы заранее задано в исходном коде. Ввод пользователя и параметры
освоим отдельно: не добавляйте `Console.ReadLine()` в текст SQL конкатенацией.

## Задание 3 Проверьте пустой результат

В предыдущем запросе замените группу на `НЕТ-00` и запустите программу.
После сообщений сборки имена студентов не выводятся: подходящих строк нет,
поэтому цикл не выполняется. Это ожидаемый результат.

Верните исходный запрос без `WHERE`, прежде чем переходить к следующему заданию.

## Задание 4 Посчитайте студентов

Теперь замените **весь** `Program.cs` следующим примером:

```csharp
using Microsoft.Data.SqlClient;

using var connection = new SqlConnection(LabDb.ConnectionString);
connection.Open();

string sql = "SELECT COUNT(*) FROM dbo.Students;";
using var command = new SqlCommand(sql, connection);

int count = (int)command.ExecuteScalar();
Console.WriteLine("Количество студентов: " + count);
```

На новой базе получится `Количество студентов: 3`.

`ExecuteReader()` нужен для чтения строк, а `ExecuteScalar()` — для одного значения.
Здесь `COUNT(*)` возвращает целое число; `(int)` позволяет записать его в переменную `count`.

3. Отдельный запуск программы подсчёта.
4. Объяснение своими словами: что делают `Open`, `SqlCommand`, `ExecuteReader` и `Read`.
