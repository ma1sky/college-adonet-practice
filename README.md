# Практика ADO.NET и SQL Server

Учимся получать данные из SQL Server с помощью простой программы на C#.
Нужны браузер и личный аккаунт GitHub. База и инструменты готовятся автоматически в Codespaces.

## Начало работы

1. Создайте свою копию через **Use this template → Create a new repository**.
   Если такой кнопки нет, используйте **Fork**.
2. В своей копии нажмите **Code → Codespaces** и создайте окружение с **2 ядрами**.
3. Дождитесь сообщения `База CollegeAdo готова` в терминале подготовки.
4. Откройте **Terminal → New Terminal** и выполните одну команду:

```bash
dotnet run --project practice
```

На новой базе получится:

```text
Анна Иванова — ИСП-21
Борис Петров — ИСП-21
Вера Соколова — ИСП-22
```

Дальше откройте [первую практику для начинающих](ПЕРВАЯ%20ПРАКТИКА.md).
Работайте только с файлом [practice/Program.cs](practice/Program.cs):
в нём четыре шага — подключение, запрос, выполнение и вывод строк.

## Если преподавателю нужно повторить подготовку базы

```bash
dotnet run --project setup
```

Эта команда создаёт отсутствующую базу и таблицы. Существующие данные сохраняются.
Подготовка отделена от программы студента, поэтому Program.cs можно свободно менять.
Файл `practice/LabDb.cs` содержит настройки подключения: оставьте его на месте.

В конце занятия сохраните работу через **Commit** и **Push**, затем выберите
**Stop codespace** в [списке своих окружений](https://github.com/codespaces).
База сохраняется при остановке, но удаляется вместе с Codespace. Код и SQL сохраняйте в GitHub.

Используются .NET 10, Microsoft.Data.SqlClient 7.1.0 и SQL Server 2022 Developer.
Пароль в конфигурации — демонстрационный, для изолированной учебной среды.
