# Практика 5. Асинхронные запросы и конфигурация

За занятие вы соберёте два отчёта по таблице `dbo.Students`. Первый выводит список студентов выбранной группы, второй считает их. Группу можно будет переключать в `appsettings.json`. [Теория и полный пример отчёта](Лекция%2005%20—%20Фабрика%20провайдеров%20асинхронный%20доступ%20и%20конфигурация.md).

Откройте свой Codespace с учебной базой `CollegeAdo`. Команды выполняйте из корня репозитория. Сохраните предыдущую работу перед заменой `practice/Program.cs`. В заданиях выполняются только запросы `SELECT`. Имена и числа ниже относятся к исходным данным. Если вы уже меняли таблицу на предыдущих занятиях, сверяйте вывод с текущими данными. [Инструкция по Codespaces](../ИНСТРУКЦИЯ.md).

## Задание 1. Перепишите подсчёт на async и await

Замените содержимое `practice/Program.cs` синхронным примером и запустите его.

```csharp
using Microsoft.Data.SqlClient;

using var connection = new SqlConnection(LabDb.ConnectionString);
connection.Open();

using var command = new SqlCommand("SELECT COUNT(*) FROM dbo.Students;", connection);
int count = (int)command.ExecuteScalar()!;
Console.WriteLine($"Количество студентов: {count}");
```

```bash
dotnet run --project practice
```

Замените `Open()` и `ExecuteScalar()` их асинхронными версиями и добавьте `await`. Получите число перед приведением типа, например двумя строками `object? result = await command.ExecuteScalarAsync();` и `int count = (int)result!;`. `COUNT(*)` без `GROUP BY` возвращает одну строку со значением `int`, в том числе `0` для пустой таблицы. Символ `!` сообщает компилятору, что здесь ожидается результат.

**Проверка.** Оба варианта выводят `Количество студентов: 3` на исходной базе. Покажите, где программа ожидает подключения, а где получает результат запроса.

## Задание 2. Создайте подключение через фабрику

В программе из задания 1 добавьте `using System.Data.Common;`. Зарегистрируйте `SqlClientFactory.Instance` под именем `Microsoft.Data.SqlClient` и получите фабрику через `DbProviderFactories.GetFactory()`. Используйте фрагмент из [раздела о фабрике](Лекция%2005%20—%20Фабрика%20провайдеров%20асинхронный%20доступ%20и%20конфигурация.md#фабрика-провайдеров) и сохраните `await connection.OpenAsync()`.

Создайте команду через `connection.CreateCommand()`. Перенесите запрос в свойство `command.CommandText` и получите число через `ExecuteScalarAsync()`.

**Проверка.** Результат совпадает с заданием 1. В `Program.cs` подключение создаётся вызовом `factory.CreateConnection()`, а команда — вызовом `connection.CreateCommand()`.

## Задание 3. Вынесите настройки в JSON

1. Добавьте пакет для чтения конфигурации.

   ```bash
   dotnet add practice/Practice.csproj package Microsoft.Extensions.Configuration.Json --version 10.0.0
   ```

2. Создайте `practice/appsettings.json` рядом с `Program.cs`.

   ```json
   {
     "Provider": "Microsoft.Data.SqlClient",
     "ConnectionStrings": {
       "College": "Server=db,1433;Database=CollegeAdo;User ID=sa;Encrypt=True;TrustServerCertificate=True;Connect Timeout=15;"
     },
     "Group": "ИСП-21"
   }
   ```

   `db` — имя сервиса SQL Server в учебном окружении. `TrustServerCertificate=True` позволяет использовать сертификат учебного контейнера. Пароль поступает из переменной `MSSQL_SA_PASSWORD`.

3. Добавьте в `practice/Practice.csproj` этот блок перед `</Project>`. При сборке JSON будет скопирован в каталог приложения.

   ```xml
   <ItemGroup>
     <None Update="appsettings.json" CopyToOutputDirectory="PreserveNewest" />
   </ItemGroup>
   ```

4. Вставьте в `practice/Program.cs` [полный пример отчёта](Лекция%2005%20—%20Фабрика%20провайдеров%20асинхронный%20доступ%20и%20конфигурация.md#пример-отчёта-по-группе) и запустите его. Для каждой проверки меняйте `Group` в JSON, сохраняйте файл и повторяйте `dotnet run --project practice`.

| `Group` | Ожидаемый вывод на исходной базе |
| --- | --- |
| `ИСП-21` | Анна Иванова и Борис Петров, каждый на собственной строке |
| `ИСП-22` | Вера Соколова |
| `НЕТ-00` | `Студенты не найдены.` |

**Проверка.** Найдите в программе имя параметра `@group`, присваивание его значения и место вызова `ReadAsync()`. Покажите, как изменение `Group` меняет вывод при том же тексте SQL.

## Задание 4. Посчитайте студентов выбранной группы

Измените запрос на `SELECT COUNT(*) FROM dbo.Students WHERE GroupName = @group;`. Сохраните настройки, фабрику и параметр `@group`. Замените весь блок с `DbDataReader` вызовом `ExecuteScalarAsync()` и выводом `Количество студентов: N`, где `N` — результат запроса.

**Проверка.** На исходных данных группы `ИСП-21`, `ИСП-22` и `НЕТ-00` дают соответственно `2`, `1` и `0`. Назовите причину, по которой для этого запроса достаточно одного значения.

## Дополнительное задание. Найдите ошибку конфигурации

Установите в `Provider` значение `Unknown.Provider` и запустите программу. По сообщению об ошибке и стеку найдите вызов, который завершился исключением. Восстановите `Microsoft.Data.SqlClient` и повторите проверку. Для самопроверки объясните, почему ошибка возникает до `OpenAsync()`.

## Если запуск не удался

| Что произошло | Что проверить |
| --- | --- |
| Компилятор не находит `ConfigurationBuilder` | Проверьте пакет в `Practice.csproj` и `using Microsoft.Extensions.Configuration;` |
| Программа не находит `appsettings.json` | Проверьте имя файла, его расположение в `practice` и `CopyToOutputDirectory` |
| Программа сообщает, что фабрика не найдена | Сверьте `Provider` с именем в `RegisterFactory()` |
| Программа сообщает, что нужен настроенный Codespace | Откройте терминал внутри Codespace этого репозитория |
| После правки группы вывод прежний | Сохраните JSON и повторите запуск с обычной сборкой |
