## Фабрика провайдеров

В первой практике выражение `new SqlConnection(LabDb.ConnectionString)` создаёт объект подключения SQL Server. Если выбор провайдера хочется задавать в настройках, точку создания объекта можно перенести в **фабрику**. Фабрика SQL Server называется `SqlClientFactory`. Она реализует общий для ADO.NET класс `DbProviderFactory`. [Получение SqlClientFactory в современном .NET](https://learn.microsoft.com/en-us/sql/connect/ado-net/obtain-sqlclientfactory).

| Общий тип ADO.NET | Реализация для SQL Server | Назначение |
| --- | --- | --- |
| `DbConnection` | `SqlConnection` | Подключение к серверу |
| `DbCommand` | `SqlCommand` | SQL-команда |
| `DbParameter` | `SqlParameter` | Параметр команды |
| `DbDataReader` | `SqlDataReader` | Чтение строк результата |

В реестре `DbProviderFactories` мы связываем текстовое имя `Microsoft.Data.SqlClient` с фабрикой `SqlClientFactory.Instance`. После этого `GetFactory()` находит фабрику по имени, а `CreateConnection()` создаёт объект. Подключение к серверу начинается при вызове `Open()` или `OpenAsync()`.

```csharp
DbProviderFactories.RegisterFactory(
    "Microsoft.Data.SqlClient", SqlClientFactory.Instance);
DbProviderFactory factory = DbProviderFactories.GetFactory("Microsoft.Data.SqlClient");

using DbConnection connection = factory.CreateConnection()
    ?? throw new InvalidOperationException("Фабрика не создала подключение.");
connection.ConnectionString = LabDb.ConnectionString;
connection.Open();
```

В этом фрагменте переменная имеет тип `DbConnection`, а созданный объект имеет тип `SqlConnection`. Для перехода на другую СУБД понадобится её пакет и фабрика, подходящая строка подключения и проверка совместимости SQL.

## Асинхронное ожидание

`OpenAsync()` возвращает `Task`, представляющий открытие подключения. `ExecuteReaderAsync()` возвращает `Task<DbDataReader>` при вызове через `DbCommand`. Оператор `await` получает результат задачи после её завершения. Если задача ещё выполняется, `await` приостанавливает выполнение метода, освобождая поток на время ожидания. [Асинхронный доступ через SqlClient](https://learn.microsoft.com/en-us/sql/connect/ado-net/asynchronous-programming), [оператор await](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/await).

В собственном методе с `await` указываем `async` перед типом результата. Например, метод подсчёта студентов может иметь сигнатуру `static async Task<int> CountStudentsAsync()`. В `Program.cs` с инструкциями верхнего уровня `await` можно использовать прямо в основном коде.

| Синхронный вызов | Асинхронный вызов | Что получаем |
| --- | --- | --- |
| `connection.Open()` | `await connection.OpenAsync()` | Открытое подключение |
| `command.ExecuteReader()` | `await command.ExecuteReaderAsync()` | Объект для чтения строк |
| `reader.Read()` | `await reader.ReadAsync()` | Признак наличия очередной строки |
| `command.ExecuteScalar()` | `await command.ExecuteScalarAsync()` | Значение первого столбца первой строки |

Порядок действий сохраняется. Сначала дожидаемся подключения, затем выполняем команду и читаем строки по одной. `using` освобождает `reader`, команду и подключение при выходе из области видимости. Асинхронность меняет способ ожидания результата. Время выполнения SQL на сервере зависит от запроса и работы сервера.

## Настройки приложения

В учебном проекте `appsettings.json` хранит имя провайдера, строку подключения без пароля и название группы. Пакет `Microsoft.Extensions.Configuration.Json` добавляет чтение JSON, а `IConfiguration` даёт доступ к значениям по ключам. `GetConnectionString("College")` читает ключ `ConnectionStrings:College`. [Конфигурация в .NET](https://learn.microsoft.com/en-us/dotnet/core/extensions/configuration).

Пароль SQL Server программа получает из `MSSQL_SA_PASSWORD`, которую уже задаёт окружение Codespaces. `SqlConnectionStringBuilder` добавляет пароль в корректном формате. При сдаче работы достаточно приложить JSON без пароля и результаты запросов.

## Пример отчёта по группе

Перед запуском установите пакет, создайте `practice/appsettings.json` и настройте его копирование по [шагам задания 3](Практика%2005%20—%20Асинхронные%20запросы%20и%20конфигурация.md#задание-3-вынесите-настройки-в-json). Затем замените содержимое `practice/Program.cs` этим примером.

```csharp
using System.Data;
using System.Data.Common;
using Microsoft.Data.SqlClient;
using Microsoft.Extensions.Configuration;

IConfiguration configuration = new ConfigurationBuilder()
    .SetBasePath(AppContext.BaseDirectory)
    .AddJsonFile("appsettings.json", optional: false)
    .Build();

string? groupName = configuration["Group"]?.Trim();
if (string.IsNullOrWhiteSpace(groupName) || groupName.Length > 20)
{
    Console.WriteLine("Укажите в Group название группы длиной от 1 до 20 символов.");
    return;
}

string providerName = configuration["Provider"]
    ?? throw new InvalidOperationException("В appsettings.json отсутствует Provider.");
DbProviderFactories.RegisterFactory(
    "Microsoft.Data.SqlClient", SqlClientFactory.Instance);
DbProviderFactory factory = DbProviderFactories.GetFactory(providerName);

string baseConnectionString = configuration.GetConnectionString("College")
    ?? throw new InvalidOperationException("В JSON отсутствует ConnectionStrings:College.");
string password = Environment.GetEnvironmentVariable("MSSQL_SA_PASSWORD")
    ?? throw new InvalidOperationException("Запустите проект в настроенном Codespace.");
var connectionSettings = new SqlConnectionStringBuilder(baseConnectionString)
{
    Password = password
};

using DbConnection connection = factory.CreateConnection()
    ?? throw new InvalidOperationException("Фабрика не создала подключение.");
connection.ConnectionString = connectionSettings.ConnectionString;
await connection.OpenAsync();

using DbCommand command = connection.CreateCommand();
command.CommandText = """
    SELECT FullName, GroupName
    FROM dbo.Students
    WHERE GroupName = @group
    ORDER BY StudentId;
    """;

DbParameter groupParameter = command.CreateParameter();
groupParameter.ParameterName = "@group";
groupParameter.DbType = DbType.String;
groupParameter.Size = 20;
groupParameter.Value = groupName;
command.Parameters.Add(groupParameter);

using DbDataReader reader = await command.ExecuteReaderAsync();
bool found = false;
while (await reader.ReadAsync())
{
    found = true;
    Console.WriteLine($"{reader.GetString(0)} — {reader.GetString(1)}");
}

if (!found)
{
    Console.WriteLine("Студенты не найдены.");
}
```

`AppContext.BaseDirectory` указывает на каталог собранного приложения. `optional: false` делает отсутствие JSON ошибкой при запуске. Значение `Group` читается при старте, а параметр `@group` передаёт его в запрос отдельно от текста SQL. `DbType.String` и размер `20` соответствуют столбцу `GroupName` типа `nvarchar(20)`.

Для `Group` со значением `ИСП-21` программа выводит две строки на исходной базе.

```text
Анна Иванова — ИСП-21
Борис Петров — ИСП-21
```
